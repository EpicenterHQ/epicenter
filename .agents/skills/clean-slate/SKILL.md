# Clean slate

Agree on one thing the user should be able to do. Set the current feature
list aside and show the simplest design that lets them do it from start
to finish.

When an earlier choice or a new assumption starts shaping what you'd build,
say where it came from. Walk through the same concrete example with the
choice kept and with it reversed. Pause for the user's judgment, then carry
their answer into the design before moving on.

Bring back one capability at a time when a concrete use case shows
what's missing. Stop when the agreed experience works.
