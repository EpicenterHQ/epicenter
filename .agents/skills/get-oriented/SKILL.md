# Get oriented

Start with what the person is trying to understand. Show the few pieces
that explain what’s happening and how they fit. Keep the details that
would change their judgment. If there’s a decision, show what’s already
true and what the choice would change.

Use plain English. If a diagram, a short blockquote, or one concrete
example makes the idea easier to see, use it. When code would help, show
what someone would actually write in a small snippet. Use TypeScript
when it fits.

If the thing really is just a file, a command, or a familiar tool, say
so and show what that means in practice. If it could be just plain X,
show what work X could take over and what that would change.

If they ask again, work out what they still need to see and show it
another way.
