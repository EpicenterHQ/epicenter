# Security

Please report a vulnerability privately, by email to
[github@bradenwong.com](mailto:github@bradenwong.com), not in a public issue or
in Discord. Say what is affected, how to reproduce it, and what an attacker
could do with it.

This covers Whispering and `epicenter serve`. Only the latest Whispering
release and current `main` get fixes.

Before reporting something about `epicenter serve`, read
[who can read your files](docs/vision.md#who-can-read-your-files): anyone who
can reach an Epicenter's computer can call every action by design, so that
alone is not a vulnerability.
