## Default Permission

List the microphones and read one's level, record a take into a folder the file system scope allows, and stop that recording.

#### This default permission set includes the following:

- `allow-inputs`
- `allow-open-meter`
- `allow-close-meter`
- `allow-start`
- `allow-stop`
