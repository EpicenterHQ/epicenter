# A, refined

A development-only refinement of the independent software studio study. The original remains intact.

## Visual plan

Paper #f3ece0, inset paper #e9dfcd, ink #1e1a16, secondary ink #4b433a, accent #c4431f. Keep A’s palette and Iowan/Palatino display family. Use Avenir/Segoe for body prose, navigation and controls; monospace only for file examples. Keep the stepped, left-aligned headline and geometric rings as the distinctive moment.

Hero: navigation, a roman serif headline, supporting text beside its last line, then the foundation and app examples. Reduce the empty space before the foundation. Remove the decorative eyebrow, numbered folios and paper noise. Keep the file tabs, Whispering gesture, Vocab practice and availability ledger.

The heading caps at 6rem; body prose is 17–18px with 1.55 leading. Sans body text restores the contrast between the display voice and useful explanation. Repeated section fades are removed so content is visible on arrival. The rings retain the original authored moment.

## Scope

Uses project frontend-design and Impeccable guidance, with the user’s warm direction taking priority. No new product claims, releases or recording features. A is preferred as a direction, not approved for production. This preview preserves app attribution, links and sample behavior.

## Verification notes

Desktop at 1440px and phone at 390px showed no horizontal document overflow. File tabs, practice reveal and mobile menu worked. Impeccable's mechanical scan prompted enlargement of 10.5px sample and status labels to 12px. The navigation underline uses a border instead of a gradient, which the static scan mistook for a solid text background. Its cream-palette warning is an intentional choice; large display leading and the geometric rings follow the incumbent world. Section-padding warnings require rendered judgment: the sections have responsive block padding, confirmed in the browser.

## Visual cleanup

The accepted direction is files in the middle with apps around them. This pass preserves it. Hero rings fade before the section boundary; curved labels are shown only when their entire bounding box fits, so a partial phrase cannot be cut by the next section. The file panel is square to the grid for crisp text. Status badges use flex layout with explicit leading and padding instead of table display. The large footer wordmark uses the established serif and a complete baseline, with its existing width-fit behavior retained. Desktop, intermediate and phone layouts were inspected.
