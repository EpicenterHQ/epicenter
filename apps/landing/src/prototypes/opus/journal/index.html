01 Foundation

Everything radiates from your files.

The plan is plain: your data lives in two kinds of files that you keep, and apps built on Epicenter read and write them. Switch apps and the files stay put.

In developmentThe file foundation is still being built. Read this section as direction, not a feature list.

.md

Markdown for words

Notes, drafts and lists as plain text. You can read them in any editor, compare versions line by line, and back them up like any other file.

.sqlite

SQLite for records

Structured data in a single database file. SQLite is public domain and widely supported, so plenty of other tools can already open it.
