# The machine: one engine, found folders, moves, and restore

**Date**: 2026-11-04
**Status**: Draft
**Owner**: Epicenter

## One sentence

Every program on a machine reaches one engine through `~/.epicenter`, each
app signs in as its site, Epicenter finds folders by looking in `~/Epicenter`
instead of keeping a list, your own `git` stays plain Git, and Epicenter can
move a folder or restore one from the account.

Decisions: [ADR-0713](../docs/adr/0713-one-epicenter-engine-per-machine-syncs-every-apps-folder.md)
(one engine), [ADR-0733](../docs/adr/0733-your-own-git-in-an-epicenter-folder-is-plain-git.md)
(plain Git, the engine as a link), [ADR-0748](../docs/adr/0748-epicenter-ships-a-portable-git-inside-the-app.md)
(the bundled portable Git), [ADR-0734](../docs/adr/0734-every-file-other-than-a-note-is-kept-whole-in-git-lfs.md)
(merge rule), [ADR-0735](../docs/adr/0735-sync-gives-files-a-history-it-never-merges-two.md)
(first sync and restore), [ADR-0715](../docs/adr/0715-the-epicenter-app-browses-every-folder-and-document-a-person-has.md)
(Epicenter browses), [ADR-0718](../docs/adr/0718-epicenters-machinery-on-a-machine-lives-in-a-hidden-home-every-program-reads.md)

(sign-in by site), and [ADR-0721](../docs/adr/0721-an-apps-folder-is-derived-never-stored.md)

## Why now

Phase 1 made every folder's path derivable. The machine still kept a list of
folders in the global Git configuration, installed the CLI by a symlink in
`~/.local/bin`, writes the engine's path into Git configuration (the global
credential helper, each folder's merge driver), relies on the system's
`git-lfs`, signs in once per program, joins a second machine's folder by
merging two unrelated histories, and offers no way to move a folder or
restore one from the account.

## Work, in commit order

| # | Commit | Wave |
| --- | --- | --- |
| 0 | Plain refusal messages; Git LFS set up completely or not at all | A |
| 1 | Sign-in spike: answered no; recorded in ADR-0731 | A |
| 2 | The engine is a link into the app (ADR-0733): `~/.epicenter/bin/epicenter` (`~/.epicenter-dev/bin` in development) links to the Epicenter app's bundled CLI, replacing the copy `a3208457d3` shipped; the CLI build states its environment; a portable Git with Git LFS (dugite-native) ships inside the app and `locateGit` returns it for Epicenter's runs, so no Git installer prompt is shown (ADR-0748), once a license review of distributing GPLv2 Git passes. The `~/.local/bin` symlink is already gone; `git` and `git-lfs` still come from the system today | A |
| 3 | Folders are found, not listed: the CLI and Epicenter scan the library root and owner folders, following links, and sync folders carrying `epicenter.synced`; the global `epicenter.folder` and `epicenter.devFolder` keys retire | A |
| 4 | `epicenter move <name> <dest>`: move the folder and leave a link at its derived path; Epicenter's "Move…" runs it | B |
| 5 | The account's folders beside the local ones in Epicenter, and "Restore": check the repository out at its derived path, or, with a folder there, add this Mac's files on top of it in one commit (ADR-0735); no unrelated-history merge, join heuristic, or `epicenter.joinPending` | B |
| 6 | Your git is plain Git (ADR-0733): no global credential helper, no per-repository merge driver path, no LFS hooks; sync passes the driver on each run | B |
| 7 | Each app signs in as its site (ADR-0731, ADR-0732): origin clients on the desktop, `https://epicenter.so` for Epicenter and the CLI, the refresh-token file in AppData, the site from the runtime, `connectAccount()` without identity options | B |

Each wave closes with a three-seat review (two Codex, one Claude). Each
commit builds, passes its own tests, and leaves every app working.
