# Greenfield pass

Use [rethink](../../.agents/skills/rethink/SKILL.md) to pursue the best possible
version of the requested target, develop the destination through dialectic, and
work backward to realize it.

The request supplies the target, intended outcome, explicit constraints, and
whether the work is exploration or implementation. Follow existing authorization;
do not add a separate approval gate to every phase.

The skill owns the design method and its references own radical options,
greenfield judgment, and clean-break execution. Keep the invocation focused on
what varies for this task. When drafting an explicit agent goal, use
[agent-goal](../../.agents/skills/agent-goal/SKILL.md) to state the objective,
starting context, completion evidence, and stop condition.

For sustained mechanical cleanup, use
[collapse-pass](../../.agents/skills/collapse-pass/SKILL.md). For final inspection
of implemented changes, use
[post-implementation-review](../../.agents/skills/post-implementation-review/SKILL.md).
