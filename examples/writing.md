# The writing app

`writing/` is the code of the Writing app, kept as it is in the Epicenter
that maintains it. It holds no notes: each person's notes stay in their own
Epicenter's private `apps/writing/data/`. There is no named template or
bundled writing app in the `epicenter` command.

Each person who takes this code owns their copy and its records. Nothing
updates a copy later; source changes are compared and adapted by hand.
